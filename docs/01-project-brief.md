# Project Brief: Restaurant Self-Ordering System

## Project Description

A large, busy, high-end restaurant is experiencing delays and order inaccuracies due to its reliance on waiters to manually take and relay customer orders, particularly during peak hours. To improve operational efficiency and enhance the customer experience, the restaurant has decided to implement a self-ordering system in which each table is permanently fitted with a non-portable, tablet-like interface running a JavaFX application. The interface is securely mounted on the table and allows customers to browse the menu, customize their selections, and place orders directly from their tables.

In the kitchen, a separate JavaFX-based Kitchen Display interface presents incoming orders in real time, enabling kitchen staff to view, prioritize, and update the status of each order as it progresses from preparation to completion. The system must ensure reliable and responsive communication between the customer ordering interfaces and the kitchen display, even during periods of high demand.

For the purpose of this project, both the customer ordering interface and the kitchen display will be developed as desktop JavaFX applications. The customer ordering interface should simulate a tablet experience by running in full-screen mode and incorporating a touch-friendly design.
